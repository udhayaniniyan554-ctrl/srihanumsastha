# Sri Hanum Sastha Enterprises — Chair Catalogue Website

Official chair catalogue website for **Sri Hanum Sastha Enterprises**, Coimbatore.

## Website Features
- **Modern, Responsive Design**: Inspired by `srihanumsastha.com` with clean presentation inspired by Featherlite.
- **100% Genuine PDF Photographs**: Contains 222 chair models directly extracted from the official catalogues:
  - **Office Chairs** (122 models) — Ergonomic task, high-back, mid-back, mesh, and executive chairs with Nylon/Chrome base options.
  - **Visitor Chairs** (48 models) — S-frame, cantilever, 4-leg, PP leg, and cushion conference visitor chairs.
  - **Lounge & Soft Seating** (24 models) — High-comfort lounge seating, mould designs, and modern accent chairs with technical schematics.
  - **Dining Chairs** (21 models) — Solid wood leg, gold frame, and upholstered dining models with dimensional diagrams.
  - **Stools & Additional Seating** (7 models) — Stainless steel, wooden seat, cushion, and heavy-duty utility stools.
- **Strict Brand Rules**:
  - No PROMAX branding or catalogue publication years anywhere.
  - No outside stock images or AI images — only genuine photographs from the uploaded PDFs.
  - Catalogue-only: No shopping cart, checkout, payment, login, or registration.
  - Prominent pricing disclaimer: *"Prices may change. Please contact us to confirm current prices and availability."*
- **Relative's Business Details in Footer**:
  - Company: **Sri Hanum Sastha Enterprises**
  - Address: **173, First Floor, KK Lane Street, Avinashi Road, Coimbatore, 641018**
  - Phones: Clickable `tel:9688727284` and `tel:8695706013`
  - Separate call buttons: **Call 9688727284** & **Call 8695706013**

## How to Run the Website Locally
Start the server using Python:
```bash
python app_server.py
```
Or with standard library server:
```bash
python server.py
```

Then open your browser at:
[http://localhost:8080](http://localhost:8080)
